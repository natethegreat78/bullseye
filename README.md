# A&D Bullseye — macOS Computer Edition

Download the latest unsigned preview from [Releases](https://github.com/natethegreat78/bullseye/releases).

```text
A&D Bullseye — macOS Computer Edition (unsigned preview)

1. Extract this ZIP into a folder you keep on your Mac, not a temporary ZIP viewer.
2. Double-click Start Bullseye.command. Keep its Terminal window open.
3. Your default browser opens to the program. Create your local account.
4. Add your FFL details, then enter records and print/download your documents.
5. Press Control-C in the launcher's Terminal window when finished.

Choose the Apple Silicon download for M-series Macs; choose Intel for Intel Macs.
The included runtime means you do not need Node.js, a database installation,
Homebrew, an app store account, or an internet connection to use this edition.

This preview is not signed/notarized by Apple. macOS may block its first launch.
Do not disable Gatekeeper or other system protections. A signed/notarized release
and actual macOS testing are required before broad commercial distribution.
If launch is blocked, stop and request a signed build rather than changing system
security settings. macOS binaries/launcher were packaged on Linux, not tested on
an actual Mac. Core server, records, PDF and backup flows are tested separately.

DATA AND UPDATES
Records live outside the download folder:
~/Library/Application Support/A&D Bullseye/
Create an encrypted backup before replacing the download folder.
Replacing the download folder must not delete or reset this data folder.
The hosted edition's records are separate and are NOT automatically copied here.
Only one copy of Bullseye may use this data folder at a time.

BACKUPS
Open Local Backup to create a password-protected .bullseye-backup file.
Save a copy on a different physical drive. A backup on the same drive alone does
not protect against that drive failing. Keep the backup password safely: it
cannot be recovered. Working files are protected by OS permissions, NOT encrypted
by the application; enable FileVault for disk protection.
Restore requires the backup password, your current local account password and
explicit confirmation. Accounts and records are replaced with those in the
backup. The program restarts. Sign in using the account saved in the backup.
Previous records/documents are retained under the data folder's recovery folder.
Local record changes/deletions retain previous values in a revision history.
Use Local Backup to export the complete records and revision history to CSV.
This history is an organization/safety feature, not tamper-proof certification.
Automatic post-restore sessions are intentionally invalidated.

OFFLINE LIMITS
Local records load and save even when the browser reports that the internet is
offline. Keep Start Bullseye.command running; this edition uses its local server,
not a hosted website. Open http://127.0.0.1:47831 in your browser.
In COMM, create message templates, select an acquisition, and copy a generated
message into your own email, text program or document. Templates are stored on
this computer and included in encrypted backups. Missing fields are marked:
replace these before copying. Bullseye never sends the copied message for you.
Email, SMS, customer public links, provider configuration and online payment
processing are unavailable. Manual fee/payment records remain local.
Preparing a mapped PDF is not a completed electronic purchaser questionnaire.
No regulatory compliance guarantee is made; compliance is the operator's
responsibility. Keep required physical records and readable exports as needed.

macOS networking is local to this computer (127.0.0.1) only. Phone access is not
included. Updates are manual downloads; there is no mandatory online activation.

```
